# Резюме — Наталья Арапова

## Описание проекта
Одностраничное сайт-резюме с интерактивными элементами: фильтрация навыков по категориям, поиск по навыкам, переключение светлой и тёмной темы с сохранением выбора. Проект выполнен в рамках вступительного задания.
